Fayda two-phone test plan

Phone A runs the Seller app, phone B the Buyer app. Mark each test case Pass, Fail, Blocked or Skip, add a comment, and create or fix test cases. Everyone sees the same results.

Anyone with this link can mark test cases, comment and edit test cases. Nothing can be deleted: a removed test case is only hidden. Results are kept per run, so start a new run (change the Run box) to test again from scratch.

If something fails: note the screen and the time in the comment. 429 "Too many requests": wait a minute (sign-in is limited to 20 a minute). No push: check notification permission.
